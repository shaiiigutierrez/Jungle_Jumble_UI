# Jungle Jumble UI

Jungle Jumble UI is a UI/UX prototype designed for a jungle-themed application.  
The project focuses on creating an engaging and user-friendly interface using Figma.

## Features

- Modern UI design
- User-friendly interface
- Interactive prototype
- Jungle-themed visuals
